# PCD Assignment 2: Image Enhancement

Penerapan *image enhancement* untuk citra gelap, terang, kontras rendah, dan buram dengan metode yang disesuaikan untuk masing-masing citra.

- *Logarithmic transformation* untuk citra gelap
- *Gamma transformation* untuk citra terang
- *Contrast stretching* untuk citra kontras rendah
- Laplacian *filtering* untuk citra buram
